사용자 인증 연구소

패스워드 이후의 인증 수단(OTP·MFA, PKI, FIDO/패스키, SSO, 생체)을 기초부터 실제 쓰이는 방식까지 — 박사 디펜스 준비 중 시작한 공부 기록

패스워드 보안을 연구하면서 정작 패스워드 "다음"에 오는 인증 수단들을 체계적으로 알지 못한다는 걸 깨달았다. 이 사이트는 그 공백을 채우는 핸드북이다. 블로그가 아니라 주제별 페이지가 쌓이는 위키이고, 각 페이지는 다시 읽었을 때 5분 안에 핵심을 복기할 수 있도록 쓴다.

페이지 공통 틀

모든 주제 페이지는 같은 순서를 따른다. 한 줄 정의 → 동작 도식(시퀀스) → 무엇을 지키고 무엇을 못 지키나(위협 모델 표) → 실제 쓰이는 곳 → 흔한 오해 → 내 연구와의 접점 → 참고 표준·문헌. 설명은 1차 출처(RFC, W3C/FIDO 스펙, NIST SP, 공식 문서)로 대조한 것만 확정으로 쓰고, 확실하지 않은 부분은 추정으로 표시한다.
